# UML Diagrams

These diagrams are provided in PlantUML format for the TCS-504 System Design assignment.

## Class Diagram

Source: `docs/class-diagram.puml`

The class diagram shows the major classes, three compartments (where applicable), visibility markers, multiplicities, and composition, aggregation, association, and inheritance relationships.

## Sequence Diagram

Source: `docs/sequence-diagram.puml`

The sequence diagram models a customer booking one seat and paying through UPI. It includes lifelines, activation bars, synchronous calls, return messages, and object-creation messages.

## How to view

Open either `.puml` file in a PlantUML-compatible editor/viewer, or use a PlantUML extension in VS Code/IntelliJ IDEA.
